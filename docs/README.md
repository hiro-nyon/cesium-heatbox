# Documentation Index（ドキュメント索引）

This directory is the canonical source for maintained documentation. Files under `docs/api/` are generated from JSDoc, and synchronized pages under `wiki/` are generated by `npm run wiki:sync`.

## Generated Documentation（生成ドキュメント）

- `docs/api/`: generated HTML API pages. Regenerate with `npm run docs`; do not edit directly.
- synchronized `wiki/*.md` pages: generated from the mappings in `tools/wiki-sync.js`; edit their canonical source files instead.
- hand-written Wiki guides that are not in the synchronization map remain maintained directly in `wiki/`.
